# Cloud Student Task Manager

A beginner-friendly cloud computing mini-project built with **Python + Streamlit + Supabase**.

## Features
- Add academic tasks with subject, due date and priority
- Store tasks in a hosted Supabase PostgreSQL database
- Mark tasks as completed
- Search and filter tasks
- View total, completed, pending and overdue task counts
- Deploy the web application using Streamlit Community Cloud

## 1. Create the cloud database
1. Create a free project at https://supabase.com/.
2. Open **SQL Editor** in your Supabase project.
3. Run this SQL:

```sql
create table public.tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  subject text,
  due_date date,
  priority text default 'Medium',
  completed boolean default false,
  created_at timestamptz default now()
);

alter table public.tasks enable row level security;

create policy "Allow app access to tasks"
on public.tasks
for all
to anon
using (true)
with check (true);
```

This policy is suitable only for a classroom demonstration with non-sensitive sample data. For a production app, add user authentication and restrict each user to their own records.

4. Go to **Project Settings → API**.
5. Copy the **Project URL** and the **anon/public key**. Do not use the service-role key in a public app.

## 2. Run locally
Install Python 3.10 or later, then open a terminal in this project folder:

```bash
pip install -r requirements.txt
```

Create a folder named `.streamlit`, then create `.streamlit/secrets.toml`:

```toml
SUPABASE_URL = "paste-your-project-url"
SUPABASE_KEY = "paste-your-anon-public-key"
```

Run:

```bash
streamlit run app.py
```

The app opens in your browser, usually at http://localhost:8501.

## 3. Deploy online with Streamlit Community Cloud
1. Create a GitHub account if you do not already have one.
2. Create a new GitHub repository, for example `cloud-student-task-manager`.
3. Upload `app.py`, `requirements.txt` and `README.md` to the repository. Do not upload your `secrets.toml` file or database keys.
4. Sign in to https://share.streamlit.io/ using GitHub.
5. Select **Create app**, choose your repository, branch and `app.py`, then deploy.
6. Open the deployed app's **Settings → Secrets**.
7. Paste the two lines from your `secrets.toml`, using your own Supabase values, and save.
8. Restart/redeploy the app. Streamlit will provide a public URL that you can share.

**Important:** I cannot publish to your GitHub or Streamlit account from this chat. You must complete the account-authorised deployment steps above; the public URL is generated by Streamlit after deployment.
